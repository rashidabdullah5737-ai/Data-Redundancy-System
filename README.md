# CodeAlpha - Data Redundancy Removal System

## Overview
A Python Flask-based application that validates data and identifies duplicate records using SHA-256 hashing.

## Technologies
- Python
- Flask
- SQLite
- HTML and CSS
- SHA-256

## Features
- Input validation
- Duplicate record detection
- SHA-256 hashing
- SQLite database integration
- Web-based dashboard
- Prevention of duplicate entries
